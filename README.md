# Lopastra — лендинг доставки дронами

Одностраничный сайт с 3D-сценой, которую ведёт прокрутка. Ночной район: дрон забирает коробку
с крыши склада, летит над жилым домом, рекой и парком и опускает посылку на тросе к двери.
Для каждой секции страницы в сцене задан свой ракурс камеры.

## Запуск

```
npm install
npm run dev
```

Сборка: `npm run build`, результат в `dist/` — статика для любого веб-сервера.

## Как устроено

- **Сцена** — `public/models/drone.glb`: карта района, дрон, коробка, трос и камера с анимацией
  на 240 кадров. Собирается из исходников в `blender/`:
  ```
  /Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python blender/build_drone_map.py
  ```
  Скрипт строит сцену, проверяет каждый кадр (дрон ничего не задевает, камера не внутри зданий,
  обзор не закрыт, дрон в кадре и не под текстом), выгружает `drone.glb` и сохраняет
  `blender/drone-map.blend` с «Камерой сайта» для просмотра в Блендере.
- **Прокрутка** — `src/pages/landing/hooks/use-landing-scroll.hook.ts`: Lenis, первый экран
  и последний блок управляются скроллом, секции между ними перелистываются за одинаковое время
  (колесо, тачпад, клавиши).
- **3D** — `src/units/scene`: React Three Fiber, камера берётся из пустышек сцены, ночное освещение,
  туман, свечение. Поверх анимации из Блендера — вращение винтов и покачивание дрона
  (`lib/specials.util.ts`).
- **Тексты** — `src/content/landing.content.ts` и `extras.content.ts`.

Бренд и продукт вымышленные.
